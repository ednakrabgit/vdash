# VDASH - Volvo Diagnostic Software (D5T5)

ชุดโปรแกรม **VDASH (VDASH2)** สำหรับวิเคราะห์ระบบรถยนต์ Volvo (อ่าน/ลบโค้ด DTC, ดูค่าสด, รีเซ็ตไฟเซอร์วิส, ปลดเบรกมือไฟฟ้า และตั้งค่าฟังก์ชันพื้นฐาน) รองรับทั้งแพลตฟอร์ม **P3** และ **SPA**

## ไฟล์ในชุดนี้

- **`vdash-setup.exe`** — ตัวติดตั้งมาตรฐาน (แนะนำ) จะติดตั้งลงที่ `%LOCALAPPDATA%\VDASH` พร้อมสร้างทางลัดบนหน้า Desktop และตั้งค่า Windows Firewall อัตโนมัติ
- **`VDASH2/`** — ตัวโปรแกรมแบบพกพา (Portable) เวอร์ชันล่าสุด สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้ง
- **`Run-VDASH.bat`** — สคริปต์คลิกเดียวเพื่อเปิดโปรแกรม `VDASH2\Vdash.Frontend.exe` จากโฟลเดอร์นี้โดยตรง
- **`portable.zip`** — ไฟล์ต้นฉบับแบบ Portable สำรอง

---

## วิธีติดตั้งและใช้งาน

### วิธีที่ 1: แบบติดตั้งลงเครื่อง (แนะนำ)
1. ดับเบิลคลิก **`vdash-setup.exe`** แล้วกดติดตั้งตามขั้นตอน
2. เปิดโปรแกรมผ่านไอคอน **VDASH2** บนหน้า Desktop

### วิธีที่ 2: แบบพกพา (Portable ไม่ต้องติดตั้ง)
1. ดับเบิลคลิก **`Run-VDASH.bat`** หรือเปิดไฟล์ **`VDASH2\Vdash.Frontend.exe`**

---

## การเชื่อมต่อกับรถยนต์ (เช่น Volvo XC60 ปี 2017)

1. **โฉมแรก (Gen 1 / แพลตฟอร์ม P3, 2008–2017)**
   - ใช้ร่วมกับกล่อง **Volvo DiCE** (ต้องมีไดรเวอร์ J2534 PassThru เช่น SETEK DiCE ในเครื่อง) หรือสาย **J2534 / Mongoose**
2. **โฉมใหม่ (Gen 2 / แพลตฟอร์ม SPA, ปลายปี 2017 ขึ้นไป)**
   - ใช้สาย **VOE (Volvo OBD to Ethernet)** หรืออุปกรณ์ที่รองรับใน VDASH
3. **ขั้นตอนการสแกน**
   - เชื่อมต่ออินเทอร์เน็ตและล็อกอินด้วยบัญชี D5T5 (สมัครฟรีในตัวโปรแกรมหรือที่ [d5t5.com](https://d5t5.com))
   - เสียบสายเข้าพอร์ต OBD-II ของรถ และบิดกุญแจ/กดปุ่มสตาร์ทไปที่ตำแหน่ง **Ignition ON (ตำแหน่ง II)** โดยไม่ต้องติดเครื่องยนต์
   - กดปุ่ม **CONNECT** ในหน้าโปรแกรม VDASH
